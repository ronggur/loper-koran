Run UI-2, langkah 3 sampai 6 dari urutan porting redesain UI (`docs/design/redesain/README.md` bagian 6) **dalam satu PR**: layar **hasil**, **koran**, **jeda**, **tutorial**, **banner**, dan **HUD rute** (hanya tombol jeda). **Amandemen scope (permintaan pemilik 2026-10-24, setelah SPEC ditulis):** "font size di bengkel dan halaman hasil terlalu kecil" dan "Atur ulang hud agar lebih efisien dan ux lebih bagus. Permintaan pemilik 2026-10-24: "Langsung aja semua jadi 1 PR" (setelah PR #64 UI-1 dibuka, menjawab usulan memecah per layar). Ini menggantikan "satu layar per run" di README redesain bagian 6 dan 1.

Satu bahasa tombol, kartu, dan panel di semua layar (keluhan pemilik 2026-10-23: "terlalu kecil, terlalu kosong, tombol polos"): hasil sebagai struk antaran, koran yang terasa koran, jeda/tutorial/banner dengan panel dan tombol baru, tombol jeda HUD berbentuk tombol.
