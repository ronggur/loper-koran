# ui_art — aset HUD dan efek kecil

Pixel art untuk HUD dan efek yang tidak dirender dari model pemain. Ukuran dan token warna mengikuti `docs/design/DESIGN_SPEC.md`, palet mengikuti `docs/ART_DIRECTION.md` 2.4.

## Menjalankan

```
pip install numpy pillow
python3 tools/ui_art/bel.py --out docs/design/bel     # tombol bel, efek "kring", ikon "!" (usulan)
python3 tools/ui_art/bel.py --salin                   # juga aset game 1x ke assets/sprites/ui/ (ui_bel_tombol, ui_bel_getar, ui_ikon_seru + ui_bel.json)
python3 tools/ui_art/hud_ikon.py --salin              # ikon HUD, penanda radar, 9-slice ke assets/sprites/ui/ (usulan)
python3 tools/ui_art/lencana.py --salin               # lencana milestone perunggu/perak/emas 14x14 ke assets/sprites/ui/ (run 6A2, usulan)
python3 tools/tests_cek/uji_ui_lencana.py             # bukti lencana di assets/ = keluaran skrip, palet induk, tingkat terbaca tanpa warna
python3 tools/ui_art/redesain/komponen.py --mock      # redesain UI (usulan 2026-10-23): aset komponen 1x ke build/ dan docs/design/redesain/aset/ (butuh pillow)
python3 tools/ui_art/redesain/sepeda_fullbody.py --mock  # redesain UI: sepeda bengkel dari gambar full body tanpa tokoh ke build/ dan docs/design/redesain/aset/ (butuh numpy, pillow)
python3 tools/ui_art/redesain/latar_bengkel.py --mock # redesain UI: latar bengkel 640/800 ke docs/design/redesain/latar_bengkel/ (butuh numpy, pillow, opencv-python, scikit-learn)
python3 tools/ui_art/redesain/komponen.py --salin     # run UI-1 (usulan): pasang HANYA komponen yang dipakai (tombol, panel, kartu, chip, papan alat, ikon 24 dan glif 12 yang dipakai) ke assets/sprites/ui/ (butuh pillow); lalu godot --headless --import
python3 tools/ui_art/redesain/sepeda_fullbody.py --salin  # run UI-1: HANYA menyalin keluaran resmi di docs/ (sepeda_kecil.png, sepeda.json) ke assets/sprites/ui/ui_bengkel_sepeda_kecil.png dan ui_bengkel_sepeda.json; tidak membuat ulang
python3 tools/ui_art/redesain/latar_bengkel.py --salin    # run UI-1: HANYA menyalin keluaran resmi di docs/ (latar 800) ke assets/sprites/ui/ui_bengkel_latar_800.png; tidak membuat ulang, tanpa opencv dan scikit-learn
UI_ART_SALIN_KE=/folder/uji python3 tools/ui_art/redesain/komponen.py --salin   # folder tujuan --salin diganti (ketiga skrip; bawaan assets/sprites/ui/); dipakai uji supaya assets/ tidak tersentuh
python3 tools/tests_cek/uji_ui_redesain.py            # bukti komponen dan sepeda deterministik, docs = keluaran skrip, palet induk, ukuran bingkai; sifat latar bengkel; run UI-1: assets/sprites/ui = keluaran --salin, set tepat yang dipakai, impor Lossless, slice = meta.json = Config
python3 tools/ukur_kontras_tangkapan.py docs/loop/<RUN_ID>/shots/iter<N> --awalan 1920x1080 --jenis hasil|koran|jeda|tutorial|banner|hud_c   # run UI-2: sama untuk layar baru; `--jenis hasil` juga mengukur kontras terhadap piksel latar TERBURUK bila ada `<keadaan>_latar.png` (tangkapan dengan semua teks transparan, V-10); python3 tools/bandingkan_tangkapan_hud.py docs/loop/<RUN_ID>/shots/baseline docs/loop/<RUN_ID>/shots/iter<N>   # run UI-2: HUD piksel-identik di luar pengecualian
python3 tools/ukur_kontras_tangkapan.py docs/loop/<RUN_ID>/shots/iter<N> --awalan 1920x1080   # run UI-1: kontras teks (>= 7:1) dan garis komponen dari tangkapan nyata probe_bengkel_jendela.gd + JSON persegi teks (butuh numpy, pillow; exit 1 bila ada teks < 7:1)
```

Pemasangan redesain UI memakai satu daftar tunggal, `redesain/pasang.py` (hanya data, tanpa pustaka): nama aset yang dipasang ke `assets/sprites/ui/` dan tujuannya. Ketiga skrip `--salin` dan `uji_ui_redesain.py` membacanya, jadi aset redesain yang tidak ada di daftar tidak pernah tersalin dan uji menolak berkas redesain di `assets/` yang tidak terdaftar. Layar berikutnya menambah barisnya ke daftar itu (run UI-2 menambah 32 berkas: struk, takik, lencana 32, ikon 24 dan glif untuk hasil, koran, jeda, tutorial, banner; total redesain terpasang 62). Komponen dipasang dari keluaran `komponen.py` yang dibuat saat itu juga (deterministik), sedangkan sepeda dan latar disalin dari berkas resmi di `docs/design/redesain/` (latar memakai k-means, bisa beda beberapa piksel antar-mesin, jadi tidak dibuat ulang).

## File

| File | Isi |
|---|---|
| `hud_ikon.py` | Ikon HUD 14×14 (koin, reputasi, ban, rem, rantai, misi kucing), penanda radar 8×6 dan versi masuk jangkauan 10×8, bingkai strip radar dan panel HUD 9-slice, contoh radar di atas layar `tools/env_art/fase3.py`. Penjelasan di `docs/design/hud/README.md` |
| `lencana.py` | Lencana milestone 14×14 (run fase6a2 bagian C, AC-15): medali bergantung pita biru, perunggu/perak/emas; tingkat dibedakan warna DAN jumlah garis di tengah (1, 2, 3). Hanya palet induk, deterministik, tanpa numpy. `--salin` menulis `ui_lencana_<tingkat>.png` ke `assets/sprites/ui/` |
| `redesain/komponen.py` | Aset kanvas redesain UI (usulan 2026-10-23, `docs/design/redesain/README.md`): bingkai 9-slice tombol, panel, kartu, chip, struk (gelap dan versi koran), tile arsir dan kertas, ikon 24×24, lencana 32×32, glif 12×12, papan alat bengkel, foto berita. Hanya palet induk dan token UI, deterministik (pillow saja). `--mock` menyalin hasil ke `docs/design/redesain/aset/`; `--salin` (run UI-1) memasang HANYA yang ada di `redesain/pasang.py` ke `assets/sprites/ui/` (ikon 24 dan glif 12 dipotong per sel dari sheet; aset lain belum dipasang) |
| `redesain/sepeda_fullbody.py` | Sepeda panggung bengkel dari gambar full body pemain (`docs/design/character/loper_agen/loper_agen_fullbody.png`): tokoh dibuang, bagian yang tertutup tubuh digambar ulang hanya di piksel kosong (roda belakang, rangka, sadel, gir), bayangan baru; versi 232×155 dan 116×78 (blok 2×2) plus `sepeda.json` titik penanda. Warna hanya dari palet gambar full body, deterministik (numpy, pillow). `--mock` menyalin ke `docs/design/redesain/aset/`; `--salin` hanya menyalin berkas resmi `sepeda_kecil.png` dan `sepeda.json` ke `assets/sprites/ui/` (sepeda besar tidak dipasang) |
| `redesain/latar_bengkel.py` | Latar layar bengkel dari ilustrasi AI (cara `konversi2`): k-means Lab 30 warna, rapikan tekstur, cahaya lampu jadi cincin, tanaman dihapus, versi 800 dengan pantulan tepi. Hasil numerik bisa beda beberapa piksel antar-mesin; berkas di `docs/design/redesain/latar_bengkel/` adalah keluaran resmi. `--salin` hanya menyalin `bengkel_latar_800.png` ke `assets/sprites/ui/ui_bengkel_latar_800.png` (tanpa opencv dan scikit-learn). **Lisensi komersial generator ilustrasi sumber belum dicatat; latar belum boleh masuk rilis** (`docs/ART_DIRECTION.md` 9) |
| `redesain/pasang.py` | Daftar tunggal aset redesain yang dipasang ke `assets/sprites/ui/` (run UI-1): tombol (9), panel dan kartu dan chip (9), papan alat, ikon 24 (3), glif 12 (5), sepeda kecil + JSON, latar 800 = 29 PNG + 1 JSON. Hanya data; dibaca tiga skrip `--salin` dan `tools/tests_cek/uji_ui_redesain.py` |
| `../ukur_kontras_tangkapan.py` | Pengukur kontras dari tangkapan layar nyata (`tests/probe_bengkel_jendela.gd` menulis PNG + JSON persegi teks, tombol, kartu): teks persentil 98 melawan warna terbanyak (>= 7:1), garis komponen melawan piksel di luar tepi (>= 3:1, hanya dilaporkan). Dipakai QA run UI-1. Run UI-2 (`--jenis hasil|koran|jeda|tutorial|banner|hud_c`): menambah ukuran kontras layar baru, kontrol aktif koran dan jeda wajib >= 3:1, dan untuk hasil kontras terhadap piksel latar terburuk dari tangkapan kedua tanpa teks (`<keadaan>_latar.png`, ditulis `tests/probe_hasil_jendela.gd`; exit 1 bila < 7:1) |
| `../bandingkan_tangkapan_hud.py` | Bandingkan dua folder tangkapan HUD piksel demi piksel di luar pengecualian tertulis (panel bawah, kolom kanan atas, tombol jeda, tutorial, gelembung petunjuk, derau animasi di sekitar pemain); membuktikan HUD yang tidak boleh berubah tidak berubah (run UI-2, V-9). Derau tangkapan pertama probe dan beberapa piksel animasi muncul acak antar jalan (dicatat di LOG) |
| `bel.py` | Bel "Kring Kring!" (GDD 5.4): tombol bel 40×40 tiga keadaan, garis getar 4 frame, teks "KRING!" dan "KRING KRING!", ikon "!", pratinjau GIF di atas sprite rute dan penempatan di mock HUD. Penjelasan aset di `docs/design/bel/README.md`. `--salin` (run fase3b-rintangan-skor) menulis aset game ke `assets/sprites/ui/`: `ui_bel_tombol.png` (diam, ditekan, lalu 8 frame jeda dengan cincin berkurang 8/8 sampai 1/8), `ui_bel_getar.png`, `ui_ikon_seru.png`, dan `ui_bel.json`; teks "KRING!" tidak disalin karena di game teksnya kunci terjemahan |
